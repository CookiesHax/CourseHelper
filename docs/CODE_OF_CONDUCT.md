# 行为准则

## 我们的承诺

作为社区成员、贡献者与管理者，我们承诺让每个人参与本社区的过程都免于骚扰，
无论其年龄、体型、可见或不可见的身心障碍、族裔、性征、性别认同与表达、
经验水平、教育程度、社会经济地位、国籍、外貌、种族、宗教信仰，
或性取向与性别身份如何。

## 我们的准则

有助于营造积极环境的行为示例：

- 对他人展现同理心与善意
- 尊重不同的意见、观点与经历
- 给予并欣然接受建设性反馈
- 承担责任，并向受我们失误影响的人致歉
- 以整个社区的最佳利益为出发点

不可接受的行为包括：

- 挑衅、侮辱或贬损性言论，以及人身或政治攻击
- 公开或私下的骚扰
- 未经明确许可公布他人的私人信息
- 其他在专业场合中可被合理认定为不当的行为

## 执行

辱骂、骚扰或其他不可接受行为的事例，可向维护者举报。所有投诉都将得到及时且公正的审阅与调查。
