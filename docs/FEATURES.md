# 🚀 功能特性 (Feature List)

CourseHelper 针对多账号学习通签到的复杂场景进行了优化，旨在提供原生、流畅且可靠的使用体验。

### 1. 📂 核心课程管理

* **多账号支持**：支持同时登录并管理多个账号，账号数据通过 Room 数据库本地存储。
* **课程一览**：实时同步课程列表，支持查看课程详情及待办任务（活动）。
* **智能过滤**：可选隐藏已结课或非必要课程，保持界面清爽。
* **缓存机制**：完善的 Repository 层实现，支持课程数据预加载与静默刷新，确保零延迟查看。

### 2. ✅ 签到

* **全类型覆盖**：
    * **普通签到**：一键完成基础签到。
    * **图片/拍照签到**：集成本地图片上传与 Object ID 关联处理。
    * **位置签到**：坐标校准，支持虚拟位置设定。
    * **二维码签到**：支持相册扫码或实时录入，处理带有 `enc2` 的动态二维码刷新逻辑。
    * **手势签到**：原生绘制面板，支持记录与自动提交。
    * **验证码签到**：支持数字验证码。
* **批量并行操作**：基于 Kotlin 协程并发处理，支持选定多个账号同时发起签到请求。
* **绕过人脸检测**：实时获取与自动提交人脸数据，不保存在本地磁盘。

### 3. 🧠 自动验证码系统

* **全自动打码**：内置算法可自动识别并计算滑块验证码偏移量，实现无感验证。
* **手动接管模式**：当自动识别失败时，系统会自动唤起**手动验证队列**
  。用户只需在弹窗滑动滑块，即可按序完成所有账号的验证，无需反复切换页面。
* **重试机制**：针对接口失效或验证码过期，支持自动刷新验证 Token。

### 4. 📍 定位优化

* **双引擎定位**：
    * **百度地图 SDK**：集成，提供室内外精准定位，解决传统网络定位偏差大的问题。
    * **原生 GPS 回退**：在百度服务不可用时，自动切换至系统原生定位方案。
* **虚拟位置实验室**：支持自定义经纬度坐标，并提供 POI 搜索功能，方便在复杂环境下精准定位到教室中心。
* **坐标系转换**：内置 WGS84、GCJ02 与 BD09LL 坐标系间的转换工具。

### 5. 🛠 现代化技术架构

* **全 Compose 驱动**：UI 层 100% 采用 Jetpack Compose 构建，拥有丝滑的动画效果与完美的深色模式支持。
* **MVVM 架构**：业务逻辑与表现层严格解耦，代码结构清晰，方便二次开发。
